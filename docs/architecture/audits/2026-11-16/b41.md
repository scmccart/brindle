## Violations

1. ui/src/components/tabs.rs:188-194 (also 144-147, 636, 644-647) — types R3 (MUST) — "An identity MUST be the value that stays stable, never a position or a number that is reused ... An index is valid only within the render or the call that computed it."
   - `DraggedTab` carries `/// Where the trigger was when the drag began. pub index: usize`, and `on_drop` sends `TabMove { from: dragged.index, to: ix }`.
   - The drag payload lives across frames, but the index was computed at drag start. If a tab is added, closed or reordered mid-drag (a terminal exiting, another move), `from` names a different trigger.
   - The file's own doc says a trigger's id is "the tab's own id, not its index", so a stable identity exists. `can_drop` also compares `dragged.index != ix` across frames.
   - Fix: carry the trigger's `ElementId` in `DraggedTab`. Have `TabMove` and `drop_side` resolve `from` against the current trigger order at drop time, or have the owner map the id to a current index.

2. ui/src/primitives/layer.rs:115-128 (`WindowLayers::prune`, used by 143, 157, 171) — fcis R1 (MUST), fcis R8 (MUST) — "A decision MUST be a pure function or a method of a GPUI-free model: what to ... drop" and "Every pure function and model MUST ship with unit tests".
   - Which layers to drop is decided in the registry glue: `.filter(|id| self.handles.get(id).is_none_or(|handle| handle.upgrade().is_none()))`. The decision is fused with gathering from `WeakFocusHandle`, and is untested.
   - `remove` (158-160) also decides inline to drop a window's entry when its stack is empty. Neither rule is in `LayerStack` or covered by a test.
   - Fix: add `LayerStack::retain(impl Fn(LayerId) -> bool)` (or `prune(&mut self, live: impl Fn(LayerId) -> bool) -> Vec<LayerId>`) with a unit test. The registry only supplies `handle.upgrade().is_some()`.

3. ui/src/icon.rs:242 — railway R1 (MUST), low severity and low confidence — "An expected failure MUST be in the return type ... Not ... a log line with a default returned in its place."
   - `if let Ok(path) = path.build() { window.paint_path(path, color); }` silently discards the `Err`. A failed build paints nothing, with no log and no visible state.
   - Fix: at minimum log the error. Better, split a pure `Icon::path(side, min_stroke) -> Result<Path, _>` out of `paint`, so the failure is a value that is tested.

4. ui/src/primitives/nav.rs:17-23 (used at ui/src/components/tabs.rs:102) — types R11 (SHOULD) — "A type with an invariant SHOULD have private fields and constructors that enforce it".
   - `ListNav { pub highlight: Option<usize>, pub count: usize, pub wrap: bool }` has the invariant `highlight < count`, but all fields are public, so it can be violated.
   - `tab_target` builds the struct literally and has to patch it up with `current.filter(|ix| *ix < count)`. The tests also assign `nav.highlight = Some(..)` directly.
   - Fix: private fields, with `ListNav::with_highlight(count, wrap, Option<usize>)` that clamps or drops an out-of-range highlight, and a `highlight()` getter.

5. ui/src/primitives/layer.rs:142, 152, 168 — ports R11 (SHOULD) — "GPUI globals and other process-wide state SHOULD be created in `main.rs` before the window opens."
   - `Layers` is created lazily by `cx.default_global::<Layers>()` inside `push`, `remove` and `is_top`, and `is_top`, a query, creates it as a side effect.
   - `Modalities` is created in `init`, which `main` calls. `Layers` is not covered by `init`.
   - Fix: have `init` do `cx.set_global(Layers::default())` and read through `global_mut`/`try_global`.

6. ui/src/components/tabs.rs:504-509 — fcis R10 (SHOULD, "questioned in review") — "If it chooses between outcomes from state, it moves into the model".
   - `if let (Some(index), Some(on_activate)) = (target, on_activate.as_ref()) && Some(index) != active` is an inline conditional in the key-down handler (skip the activation when the target equals the active trigger).
   - Related, in `render_trigger` (526-530): `list.on_close.clone().filter(|_| trigger.closable && !disabled)` decides inline what a trigger can do. `trigger_press` then receives the result as a `closes` flag.
   - Fix: fold both into the pure `tab_target` and `trigger_press` (for example, return `None` when the target equals `current`), with tests.

## Design smells

- ui/src/primitives/focus_visible.rs:87-101, 139-164 — the `Observers` trait exists only so a test can substitute a `Recorder`. This is close to ports R6 and testing R12 (no mocks), but it wraps registration, not a decision, so it is not counted as a violation. A test that asserts "init binds no keys" through a recorder is weaker than a structural check.
- ui/src/primitives/focus_visible.rs:33-40 — the per-window `Modalities` map never drops a closed window's entry (documented as accepted). Not covered by a rule.
- ui/src/primitives/layer.rs:166-173 — `is_top` takes `&mut App` and prunes, so a query mutates global state. `stack` and `depth` are the read-only variants.
- ui/src/primitives/nav.rs:19 and ui/src/filter.rs:14 — a persisted `highlight: Option<usize>` and `filter` returning indices. They are valid within a call (types R3), but a caller that keeps them across a list rebuild would break the rule. This is OK as written (the app's `Command` uses `keep`), but it relies on the callers.
- ui/src/components/tabs.rs:131-147, 393-398 — `TabActivate`, `TabContextMenu` and `on_close(&usize)` all deliver bare indices to the owner. They are valid for the render that built the closure, but the owner must not store them. Only `DraggedTab` (violation 1) crosses frames.
- ui/src/components/tabs.rs:497-511 — the list handles left/right/home/end itself in `on_key_down` with raw key strings, instead of through actions in `default_bindings()`. The module doc and the `list_keys_reach_the_list` test justify it, and it is not binding. Still, it is the one place the crate interprets keys outside its bindings.
- ui/src/components/toggle.rs:42-43 — `label: Option` and `icon: Option` allow `(None, None)` (types R1 in spirit). The constructors prevent it, and the builder methods cannot reach it.
- ui/src/icon.rs:144-159 — `Icon::ALL` is a hand-kept copy of the variant list. `every_icon_is_listed_once` checks duplicates, not completeness, so a new variant omitted from `ALL` would skip the geometry test (types R2/R10 spirit).
- ui/src/icon.rs:192-245 — the geometry (centring, arcs, rect corners) is computed inside `paint` against `PathBuilder`, so only `stroke_width` and the tables are unit-tested.
- ui/src/primitives/tooltip-related: ui/src/components/tooltip.rs:80-93 — the Escape-dismiss rule (`key == "escape"`, `was_shown`) is an inline closure in `Tooltip::build`, with no pure helper or test.
- Test names that are not sentences (testing R15, outside this brief's rule list): `fuzzy`, `no_stops`, `nowhere_to_go`, `nothing_to_highlight`, `from_outside_the_stops`.
- ui/src/lib.rs:20-31 — wide glob re-exports (`pub use actions::*; components::*; primitives::*`) make the public surface implicit. Not covered by a rule.

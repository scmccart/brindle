# Tasks: agents-module-structure

No behaviour changes. A **move** task is one commit: it moves code and its tests as design decisions 1–8 and 17 say, and touches nothing else beyond `mod`, `use`, visibility and re-export lines. Its check is `git show --color-moved=dimmed-zebra --color-moved-ws=allow-indentation-change HEAD`, which must show only moved lines plus those. A **type** task is its own commit, with its new tests written first. New tests are named as sentences (`testing R15`). A move that would leave `tests/architecture.rs` failing (`PURE_MODULES`, the `fcis` table) changes the check and its doc in the same commit.

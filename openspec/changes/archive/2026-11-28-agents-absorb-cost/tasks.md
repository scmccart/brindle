Each group writes its tests first and watches them fail before the code they check. Test names are sentences (`testing R15`). Nothing in a test sleeps, retries or waits on elapsed time (`testing R7`, `R8`, `R9`); the fake agent's `pace` step is used by the perf suite only, which asserts nothing (`testing R14`). The measurements in group 2 are taken before any product change in groups 4–8, so their "before" numbers are the code as it was (`testing R10`).

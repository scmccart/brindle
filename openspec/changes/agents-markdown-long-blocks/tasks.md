# Tasks

Each group writes its tests first and watches them fail before the code they check. Test names are sentences (`testing R15`). Nothing in a test sleeps, retries or waits on elapsed time (`testing R7`, `R8`, `R9`); the perf suite reports numbers and asserts nothing (`testing R14`). The measurement in group 2 is taken before any product change in groups 3–6, so its "before" numbers are the code as it was (`testing R10`). Group 4 (code's shown text once) is made whatever group 2 shows (design decision 7); groups 3, 5 and 6 only if group 2 shows the fault (design decision 1).
